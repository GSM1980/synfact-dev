# SP WAVETBL (Syntakt)

Version **0.1.0**, machine type **72**. Requires **core 2.8** (wavetables in
the pool, the tempo control); an older core refuses a bank with it.

Two wavetable oscillators, each with its own ANIM modulator on position and
level, mixed on one track. It does what the Tonverk's Wavefinder SRC machine
does; the design, the decisions and the open points are in
[docs/SP-WAVETBL.md](../../docs/SP-WAVETBL.md).

## Pages

| SYN 1 (osc 1) | SYN 2 (osc 2) | Range | What it does |
|---|---|---|---|
| TUNE | DTUN | -48.00..+48.00 / -64..+63 | semitones on both oscillators / osc 2 against osc 1, +-64 = +-1 semitone |
| LEV | LEV | 0..127 (100 / 0) | the oscillator's level; 127 alone is about -6 dB |
| POS | POS | 0..127, fine steps | the wave played, 0 the first, 127 the last; crossfades between neighbours |
| SLOT | SLOT | pool position 1..128 (65) | the wavetable or sample, by its pool position; p-lockable; never randomized (SYN+YES) or reloaded (SYN+NO): its alias is the pool sample slot's (0x1f2) |
| SPD | SPD | 0..127 (64) | ANIM's time: one-shot shapes 2 ms..30 s; looping shapes 1/16 beat..64 beats of the tempo |
| A.LEV | A.LEV | -64..+63 (0) | ANIM's depth on LEV |
| A.POS | A.POS | -64..+63 (0) | ANIM's depth on POS; +-63 covers the whole table |
| ANIM | ANIM | 12 shapes (EXP D) | Exp Down, Ramp Down, Tri, Ramp Up, Exp Up (one shot); Loop Ramp Down, Loop Tri, Loop Square, Loop Ramp Up; Random (smooth), Sample+Hold, Wavetable (the oscillator's own wave) |

Control 16 (`TMPO`) is hidden: its alias `ST_MACHINE_TEMPO_PARAMETER` makes
the core send AUDIO the tempo in it (mods/core-st/README.md, 2.8.0).

A wavetable is loaded into the project pool like a sample (Sample Manager,
from the `wavetables` folder; rows read `WT `). SLOT also takes any plain
sample of the pool, as the Tonverk does: it plays as a wavetable of
2048-frame waves (at most 64, evenly spaced; a stereo sample's L), with no
band-limited levels, so high notes alias. An empty slot or a sample shorter
than 2048 frames is silent; the page reads EMPTY SLOT or SAMPLE TOO SHORT. Wavetables go to the unit with
`long_samples put` (`docs/SP-WAVETBL.md`, section 6).

## Sound

- Pitch: the note plus TUNE; osc 2 adds DTUN. Phase increments from a
  1/16-semitone table (`tables.h`, generated by `tools/gen_tables.py` from
  formulas only).
- Each oscillator reads one of nine band-limited levels, chosen per block so
  that its top harmonic stays under 28 kHz, with linear interpolation inside
  a wave and a crossfade between the two waves around POS.
- ANIM runs once a block; position and level ramp linearly across the block.
  Every trig restarts both phases and both ANIMs.
- Output: (osc 1 + osc 2) at Q30 each, then the native declick, gain, FLTR,
  AMP and FX.

## Screen

Each SYN page is drawn as the Tonverk's Wavefinder page (`page.c`;
docs/SP-WAVETBL.md, section 3b): TUNE (DTUN) box, LEV with its bar,
[POS] and W + SLOT on top; the wave at the position in the middle, moving
with ANIM while the track plays; the position's track under it; SPD's
scale, A.LEV and A.POS bipolar bars and ANIM's shape at the bottom. Locked
controls are inverted. The wave is read from the card once per slot (core
2.8, UI API 9); the moving position comes from AUDIO's cursor records.
The page takes every knob's dial (none is painted natively: the firmware's
dial reached past the page's clearing and stayed as a mark). Pixels go
straight into the bitmap, and a moving position redraws at most every other
idle call, for a 32nd of a wave or more: about 12,900 instructions a draw
in the emulator (27,600 before 0.1.0's unit test), the native text and the
LCD transfer not counted.

## FUNC + a knob: stick to values

Holding FUNC, a knob moves from its value to the next stop in the turning
direction, one stop per detent of travel (`input.c`): TUNE by octaves
(-48..+48), POS on each whole wave of the slot's table or sample, SPD on each
of the 17 tempo divisions, LEV on 0/32/64/96/127, DTUN, A.LEV and A.POS on
-64/-32/0/+32/+63. SLOT and ANIM keep their own steps. The edit goes
through the core (Sound, lock, undo); with a trig held it makes a lock.

The value pop-up reads "name=value" on one row: the long names are short
(ANIM SH OSC 1, ANIM POS OSC 1...) and so are the shapes' (EXP D, L SQUARE...).

## The SLOT list

Turning SLOT (knob D, either page) opens the pool's list over the page, as
SAMP does on the SP machines: every position with its name, `WT` after a
wavetable and `ST` after a stereo sample, the current one inverted. YES or any
other key closes it, NO reverts the value; with a trig held (a p-lock) NO
clears the lock it made. `slot-list.c` is the SP list (samplers 1.6
`browser.inc`) made machine-neutral, in a file of its own so that the SP
machines can share it later; `input.c` is the bank module `WT SLOT LIST`
that opens it.

## Files

| File | What |
|---|---|
| `main.c` | descriptor, value formats and dials (MAIN) |
| `page.c` | the SYN pages, drawn as the Tonverk's (MAIN) |
| `slot-list.c`, `slot-list.h` | the pool list for a slot control, machine-neutral (MAIN) |
| `input.c` | the `WT SLOT LIST` module: SLOT's encoder opens the list, NO/YES (MAIN) |
| `audio.c` | the AUDIO glue: controls, pool, native declick/gain (as SY MnM) |
| `engine.c`, `engine.h` | the oscillator and ANIM, portable integer C |
| `tables.h`, `tools/gen_tables.py` | pitch, ANIM times, tempo divisions, level limits |

## Tests and cost

- `tests/test_wavetable_st.py --cc <clang> --out <folder>` (in the
  regressions): engine.c built for the host equals
  `tests/wavetable_st_reference.py` in 12 random scenarios of 400 blocks
  (every shape, tempo, table present and absent), the tables, pitch (A4 within a
  cent), the level limits, the descriptor and ANIM timing.
- `tests/test_wavetable_st_cfbench.py --cfbench <cfbench>`: instructions of one
  track's block on analog-emu's ColdFire, both oscillators on a 64-wave table:
  about 3,100 with a fixed position between two waves (a table or a plain
  sample alike), about 3,800 with ANIM on position. Instructions only, not cache stalls; no unit measurement
  yet.

- `tests/test_wavetable_st_page_emu.py --stock <OS 1.42> --bank <bank>`
  (in the regressions with Unicorn and `SYNTAKT_STOCK`): the bank's draw and
  idle on the stock routines; layout, values, the wave over its width, one
  card read per slot, the moving marker, locks, an empty slot, nothing drawn
  outside x 19..124 / y 0..51; the SLOT list on both pages (names, WT/ST
  tags), NO reverting a value and a new p-lock; PNGs with `--out`.

Not tested on a unit.
